# Crowdfunding Library

A Rust library for crowdfunding functionality developed as part of the Web3Bridge bootcamp.

## Overview

This is a modular library project showcasing Rust best practices for building reusable components in the crowdfunding domain.

## Structure

```
crowdfunding/
├── Cargo.toml           # Project manifest

    └── lib.rs           # Library implementation
```

## Getting Started

### Build

```bash
cargo build
```

### Run Tests

```bash
cargo test
```

### Generate Documentation

```bash
cargo doc --open
```
